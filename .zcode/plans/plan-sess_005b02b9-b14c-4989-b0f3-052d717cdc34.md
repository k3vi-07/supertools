# 远程组件自动注册功能 — 实施计划

## 一、核心架构

```
GitHub 仓库 (托管 .vue 源码 + registry.json)
       ↓
jsDelivr CDN (https://cdn.jsdelivr.net/gh/user/repo@main/...)
       ↓
Electron 主进程 (net 模块 fetch，绕过 CORS)
       ↓ IPC 传输源码
渲染进程 (vue3-sfc-loader 运行时编译 .vue → Vue 组件)
       ↓
defineAsyncComponent + <Suspense> (已有，零改动)
```

## 二、实现步骤

### 步骤 1：安装 vue3-sfc-loader 依赖

### 步骤 2：扩展 ToolManifest 类型
在 `types.ts` 添加 `remote` 字段：
```ts
remote?: {
  repo: string        // GitHub 仓库，如 'user/supertools-community'
  path: string        // 组件路径，如 'tools/MyTool.vue'
  version?: string    // 版本/分支/commit，默认 'main'
}
```

### 步骤 3：主进程添加远程代理 IPC
在 `src/main/index.ts` 新增 IPC handler：
- `tools:fetchRemote(url)` — 用 Electron `net` 模块获取远程文件内容（绕过 CORS）
- `tools:fetchRegistry(repo)` — 获取远程仓库的 `registry.json`（工具清单）

### 步骤 4：preload 暴露远程加载 API
在 `src/preload/index.ts` 新增：
- `window.supertools.fetchRemote(url): Promise<string>`
- `window.supertools.fetchRegistry(repo): Promise<RemoteManifest[]>`

### 步骤 5：实现远程工具加载器
新建 `src/renderer/src/utils/remoteLoader.ts`：
- 配置 `vue3-sfc-loader` 的 `loadModule` 选项
- `getFile(url)` 通过 `window.supertools.fetchRemote` 获取（经主进程代理，无 CORS 问题）
- `moduleCache` 缓存 Vue 运行时
- `addStyle` 注入 CSS

### 步骤 6：实现远程注册中心
新建 `src/renderer/src/stores/remoteTools.ts` (Pinia store)：
- `fetchRegistry()` — 从远程仓库拉取 registry.json
- `installTool(manifest)` — 下载并注册远程工具
- `uninstallTool(id)` — 移除远程工具
- `installedTools` — 已安装的远程工具列表（持久化到 localStorage）
- 白名单仓库管理

### 步骤 7：扩展 index.ts 注册器
在 `allTools` 中合并本地工具 + 已安装的远程工具：
```ts
export const allTools = [
  ...buildTools(localManifests),         // 本地内置
  ...buildRemoteTools(remoteManifests)   // 远程已安装
]
```

### 步骤 8：远程工具商店页面
新建 `src/renderer/src/views/StoreView.vue`：
- 展示远程仓库中可用的工具列表
- 一键安装/卸载
- 搜索远程工具
- 显示已安装状态

### 步骤 9：侧边栏添加"工具商店"入口

### 步骤 10：创建示例远程仓库结构
创建一个示例 `registry.json` 格式文档：
```json
{
  "name": "SuperTools 社区工具",
  "tools": [
    {
```

## 三、安全设计

- **白名单仓库**：只有用户添加的 GitHub 仓库才能加载工具
- **主进程代理**：所有远程请求经过主进程，可做过滤和缓存
- **CSP 不变**：已有 `unsafe-eval` 支持 sfc-loader 运行时编译
- **contextIsolation**：远程组件运行在隔离上下文，只能访问 `window.$he3`
